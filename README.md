# ELT-PCS R&D roadmap - WP7

## FastYield

The `PCS_FastYield.py` script implements a complete yield analysis for the PCS instrument based on inputs from the PCS R&D roadmap team. The script is based on the [FastYield](https://github.com/StevMartos/FastYield) package developed by [@StevMartos](https://github.com/StevMartos).

The script has a [companion document](https://www.overleaf.com/read/jxfkymvmnbjf#1296b6) hosted on Overleaf, which describes the astrophysical and technical assumptions as well as the implementation of the analysis.
